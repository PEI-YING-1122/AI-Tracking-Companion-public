# AI Tracking Companion v0.2.1

- Supports PNG original image sequences and matches the selected frame pattern.
- Uses compatible tracking flatten images as Maya and Nuke reference layers.
- Builds the Nuke redistort example and writes one final path to the Nuke Root node.
- Adds Workstation Setup and validates paths and tool versions before saving.
- Supports Nuke 13–17 and defaults to the lowest supported installed version.
- Requires a local installation folder on Windows.

Install and configure the tools using `QUICK_START.md`. See `docs/DEPLOYMENT_TEST_v0.2.1.md`
for a validation checklist.
